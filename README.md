### Для запуска тестов и отчета через плагин Maven и Allure.

Проект можно собрать и запустить тесты с помощью плагина **Maven** и плагина **Allure** или из консоли.
Ниже представлены шаги для правильной настройки и использования.

## Запуск проекта с Maven

1. **Очистка и запуск тестов:**
   Используйте стандартный жизненный цикл Maven:

```bash 
Lifecycle -> clean
```

```bash 
Lifecycle -> test
```

2. **Создание отчета Allure:**
   Для генерации отчета после завершения тестов используйте команду:

```bash 
allure:"report"
```

Эта команда очистит проект, запустит все тесты и сгенерирует необходимые файлы для Allure в папке
`target/allure-results/`.
Из mvn используя Allure plugin.

3. **Просмотр отчета в реальном времени:**
   Для того чтобы открыть отчет Allure в браузере, используйте команду:

```bash 
allure:"serve"
```

Эта команда запустит веб-сервер и откроет отчет Allure в браузере по умолчанию. Все изменения в отчетах будут
отображаться в реальном времени.

## Использование Maven Wrapper на Windows

1. **Запуск тестов через Maven Wrapper:**
   Для запуска тестов с использованием Maven Wrapper выполните команду:
1. **Очистка и запуск тестов:**
   Используйте стандартный жизненный цикл Maven:

```bash 
./mvnw.cmd clean test
 ```

Эта команда очистит проект, запустит тесты и сгенерирует необходимые файлы для Allure в папке `target/allure-results/`.

2. **Создание отчета Allure:**
   Для генерации отчета после завершения тестов используйте команду:

```bash 
./mvnw.cmd allure:report
```

Эта команда создает отчет в директории `target/allure-report/`, который можно будет просмотреть.

3. **Просмотр отчета в реальном времени:**
   Для того чтобы открыть отчет Allure в браузере, используйте команду:

```bash 
./mvnw.cmd allure:serve
 ```

Эта команда запустит веб-сервер и откроет отчет Allure в браузере по умолчанию. Все изменения в отчетах будут
отображаться в реальном времени.

## Примечания:

- **Allure Plugin** автоматически создает отчеты, используя данные из папки `target/allure-results/`, которая появляется
  после выполнения тестов.
- **Maven Wrapper** позволяет запускать сборку с конкретной версией Maven, которая будет автоматически скачана, если она
  не установлена на вашей системе. Это обеспечивает совместимость проекта с нужной версией Maven.
